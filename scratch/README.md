# Scratch Workspace

Use this directory for off-books, ad-hoc roundtable experiments that should not
enter repository history. Contents are ignored by git except this README and
`.gitkeep`.

Suggested local layout:

- `scratch/notes/`: temporary topic configs and source notes.
- `scratch/runs/`: raw model outputs.
- `scratch/published/`: local-only edited drafts.
- `scratch/audio/`: local-only scripts, manifests, and MP3 exports.
