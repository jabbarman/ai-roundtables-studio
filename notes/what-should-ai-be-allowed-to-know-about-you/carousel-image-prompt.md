# ChatGPT Images Prompt: LinkedIn Carousel

Use this as the prompt for ChatGPT Images.

```text
Create a 5-slide square LinkedIn carousel, 1080x1080 per slide, for a podcast episode.

Style:
- Editorial, intelligent, calm, not alarmist or hype-driven.
- Off-white or very light background.
- Deep navy / charcoal text.
- One accent colour, preferably muted teal or violet.
- Clean typography, generous spacing, high contrast.
- No company logos.
- No robot clichés, eyes, fingerprints, padlocks, glowing brains, or sci-fi imagery.
- Use simple abstract shapes suggesting bounded context: separate document cards,
  a calendar block, temporary containers, dotted boundaries, expiry markers, and
  a visible path from source to memory to deletion.
- Make all text highly legible.

Brand:
AI Roundtables Studio

Episode title:
What Should AI Be Allowed to Know About You?

Create one slide for each section below. Use only the text provided.

SLIDE 1 — The Question
What should AI be allowed to know about you?

When does useful personal context
become surveillance?

SLIDE 2 — The Scenario
An AI assistant reads your calendar,
email, documents and past chats.

It infers a health issue
and reuses an old salary file.
You never asked it to connect those dots.

SLIDE 3 — The Disagreement
Is specific permission enough?

Should sensitive inferences be off-limits?

Or should the system be unable to search
across personal data in the first place?

SLIDE 4 — The Rule That Survived
Use the least context needed
for the named task.

Expire it by default.
Never silently infer or store sensitive traits.

SLIDE 5 — Listen / Read
AI Roundtables Studio

Listen on Spotify.
Read the transcript.

Composition:
- Use the same visual system across all slides.
- Keep text inside safe margins.
- Make Slide 4 visually strongest.
- Show context cards crossing a boundary on Slides 2 and 3, then becoming
  deliberately separated and time-limited on Slide 4.
- Do not add any extra text.
```

Compact single-image option:

```text
Create a square 1080x1080 LinkedIn infographic for AI Roundtables Studio.

Title: What Should AI Be Allowed to Know About You?

Sections:
The Question — When does useful personal context become surveillance?
The Scenario — An assistant infers a health issue and reuses an old salary file without being asked.
The Disagreement — Is permission enough, should sensitive inference be banned, or should data stay in hard silos?
The Rule That Survived — Use the least context needed for the named task. Expire it by default. Never silently infer or store sensitive traits.
Listen / Read — Listen on Spotify. Read the transcript.

Use an editorial off-white background, deep navy text, muted teal or violet accents,
clean typography, and abstract bounded-context cards with expiry markers. No logos,
robot clichés, padlocks, eyes, fingerprints, or sci-fi imagery.
```
