# ChatGPT Images Prompt: LinkedIn Carousel

Use this as the prompt for ChatGPT Images.

```text
Create a 5-slide square LinkedIn carousel, 1080x1080 per slide, for a podcast episode.

Style:
- Editorial, intelligent, calm, not hype-driven.
- Off-white or very light background.
- Deep navy / charcoal text.
- One accent colour, preferably muted blue or green.
- Clean typography, generous spacing, high contrast.
- No company logos.
- No robot clichés, no glowing brains, no sci-fi imagery.
- Use simple abstract shapes suggesting evidence, explanation, uncertainty, and appeal: documents, linked citations, sliders, thresholds, and a small path from decision to challenge.
- Make all text highly legible.

Brand:
AI Roundtables Studio

Episode title:
Should an AI Have to Explain Itself?

Create one slide for each section below. Use only the text provided.

SLIDE 1 — The Question
Should an AI have to explain itself?

When does an explanation help us judge an answer,
and when does it just make the answer sound more convincing?

SLIDE 2 — The Scenario
An AI-assisted system denies a mortgage,
screens out a job applicant,
or gives medical triage advice.

It offers an explanation.
But is that explanation evidence,
or just a persuasive story?

SLIDE 3 — The Disagreement
Should users see the AI’s reasoning?

Or should they see evidence,
uncertainty,
thresholds,
citations,
and a way to challenge the result?

SLIDE 4 — The Rule That Survived
Don’t ask AI to “show its thinking” as theatre.

Ask for evidence, uncertainty, sources,
and a way to challenge the answer.

SLIDE 5 — Listen / Read
AI Roundtables Studio

Listen on Spotify.
Read the transcript.

Composition:
- Use the same visual system across all slides.
- Keep text inside safe margins.
- Make Slide 4 visually strongest.
- Use subtle arrows or stacked cards to show the movement from explanation to evidence to appeal.
- Do not add any extra text.
```

Compact single-image option:

```text

Sections:

Listen / Read — Listen on Spotify. Read the transcript.

Use an editorial off-white background, deep navy text, muted blue/green accents, clean typography, and abstract evidence/appeal shapes. No logos, no robot clichés, no sci-fi imagery.
```
