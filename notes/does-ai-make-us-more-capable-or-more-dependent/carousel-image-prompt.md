# ChatGPT Images Prompt: LinkedIn Carousel

Use this as the prompt for ChatGPT Images.

```text
Create a 5-slide square LinkedIn carousel, 1080x1080 per slide, for a podcast episode.

Style:
- Editorial, intelligent, calm, and reflective rather than alarmist.
- Off-white or very light background.
- Deep navy / charcoal text.
- One accent colour, preferably muted amber or teal.
- Clean typography, generous spacing, high contrast.
- No company logos.
- No robot clichés, glowing brains, humanoid machines, or sci-fi imagery.
- Use simple abstract shapes suggesting assisted performance and retained
  capability: a polished report, a visible source trail, linked assumptions,
  a tool being temporarily removed, and a rough fallback path.
- Make all text highly legible.

Brand:
AI Roundtables Studio

Episode title:
Does AI Make Us More Capable or More Dependent?

Create one slide for each section below. Use only the text provided.

SLIDE 1 — The Question
Does AI make us more capable
or more dependent?

Is better output the same thing
as better judgment?

SLIDE 2 — The Scenario
An analyst's AI-assisted work
earns a promotion.

Then a client challenges a figure.
The AI is unavailable.
The analyst cannot defend the number.

SLIDE 3 — The Disagreement
Must competence live in the individual?

Can it live in an auditable team workflow?

Or do we need both recurring practice
and an organisational fallback?

SLIDE 4 — The Rule That Survived
Delegate execution.

For consequential work:
explain the assumptions,
check independently,
and recover when the tool is gone.

SLIDE 5 — Listen / Read
AI Roundtables Studio

Listen on Spotify.
Read the transcript.

Composition:
- Use the same visual system across all slides.
- Keep text inside safe margins.
- Make Slide 4 visually strongest.
- On Slide 2, show a polished report connected to an AI tool, then the link
  disappearing while assumptions remain hidden.
- On Slide 4, reveal a clear three-part path: explain, check, recover.
- Do not add any extra text.
```

Compact single-image option:

```text
Create a square 1080x1080 LinkedIn infographic for AI Roundtables Studio.

Title: Does AI Make Us More Capable or More Dependent?

Sections:
The Question — Is better AI-assisted output the same as better judgment?
The Scenario — An analyst earns a promotion, then cannot defend an AI-produced figure when the tool is unavailable.
The Disagreement — Must competence live in the person, the team workflow, or both?
The Rule That Survived — Delegate execution. For consequential work, explain the assumptions, check independently, and recover when the tool is gone.
Listen / Read — Listen on Spotify. Read the transcript.

Use an editorial off-white background, deep navy text, muted amber or teal
accents, clean typography, and abstract report, source-trail, and fallback-path
shapes. No logos, robot clichés, glowing brains, humanoid machines, or sci-fi imagery.
```
