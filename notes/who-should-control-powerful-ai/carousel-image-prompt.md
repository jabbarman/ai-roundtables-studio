# ChatGPT Images Prompt: LinkedIn Carousel

Use this as the prompt for ChatGPT Images.

```text
Create a 5-slide square LinkedIn carousel, 1080x1080 per slide, for a podcast episode.

Style:
- Editorial, intelligent, institutional, and calm rather than alarmist.
- Off-white or very light background.
- Deep navy / charcoal text.
- One accent colour, preferably muted red, amber, or teal.
- Clean typography, generous spacing, high contrast.
- No company or government logos.
- No robot clichés, glowing brains, humanoid machines, flags, party-political imagery, or sci-fi scenes.
- Use simple abstract shapes suggesting divided authority: a model release gate,
  an evidence file, an independent test bench, a public authority, and a court
  review timer.
- Make all text highly legible.

Brand:
AI Roundtables Studio

Episode title:
Who Should Control Powerful AI?

Create one slide for each section below. Use only the text provided.

SLIDE 1 — The Question
Who should control powerful AI?

Who may delay a release
when the evidence is contested?

SLIDE 2 — The Scenario
A powerful model can find
software vulnerabilities.

Its safeguards can be bypassed.
A rival is ready to release.
Who gets to stop it?

SLIDE 3 — The Disagreement
Restrict dangerous deployments?

Or pause the base model
before real-world harm occurs?

SLIDE 4 — The Rule That Survived
Risk-tiered authority.

Labs provide evidence.
Independent evaluators test.
Governments act.
Courts review.
Restrictions expire.

SLIDE 5 — Listen / Read
AI Roundtables Studio

Series One finale

Listen on Spotify.
Read the transcript.

Composition:
- Use the same visual system across all slides.
- Keep text inside safe margins.
- Make Slide 4 visually strongest.
- On Slide 2, show a release gate held between benefit and bypass risk.
- On Slide 3, contrast a narrow tool restriction with a temporary model-level pause.
- On Slide 4, show five connected institutions without placing one above all others.
- Do not add any extra text.
```

Compact single-image option:

```text
Create a square 1080x1080 LinkedIn infographic for AI Roundtables Studio.

Title: Who Should Control Powerful AI?

Sections:
The Question — Who may delay a powerful AI release when the evidence is contested?
The Scenario — A model can find software vulnerabilities, its safeguards can be bypassed, and a rival is ready to release.
The Disagreement — Restrict dangerous deployments, or pause the base model before real-world harm occurs?
The Rule That Survived — Labs provide evidence. Independent evaluators test. Governments act. Courts review. Restrictions expire.
Listen / Read — Series One finale. Listen on Spotify. Read the transcript.

Use an editorial off-white background, deep navy text, muted red, amber, or teal
accents, clean typography, and abstract release-gate, evidence, testing, public
authority, and court-review shapes. No logos, robot clichés, glowing brains,
humanoid machines, flags, party-political imagery, or sci-fi scenes.
```
